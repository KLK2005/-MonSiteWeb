# MonSiteWeb - Spécialité CDWFS

Un site web professionnel présentant la spécialité CDWFS et ses services en développement web.

## Caractéristiques

- ✨ Design moderne et responsive
- 🎯 Navigation fluide et intuitive
- 📱 Optimisé pour tous les appareils
- ♿ Accessible et sémantique
- ⚡ Performance optimale

## Structure du projet

```
.
├── index.html       # Page principale HTML
├── style.css        # Feuille de styles CSS
├── .gitignore       # Fichier d'exclusion Git
└── README.md        # Documentation du projet
```

## Sections

1. **À propos** - Présentation de la spécialité CDWFS et formations proposées
2. **Services** - Liste complète des prestations et services offerts
3. **Contact** - Informations de contact

## Installation et utilisation

1. Clonez le repository :
   ```bash
   git clone <url-du-repo>
   cd MonSiteWeb
   ```

2. Ouvrez le fichier `index.html` dans votre navigateur
   - Ou utilisez un serveur local : `python -m http.server 8000`
